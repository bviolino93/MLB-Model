MLB Edge v0.9.2-CFB-UI

This release is a UI/workflow parity update based on the CFB Edge production app.

What changed
============
- MLB Edge now uses the same dark navy visual system as CFB Edge.
- Matching product hero, version pill, live status strip and A/B/C/D legend.
- Mobile-first layout with the same spacing, typography, cards and expanders.
- Single Game now opens with a branded matchup header, team logos, projected runs and model total.
- Current automatic market is graded immediately using the SAME calibrated v0.9 decision layer as Full Slate.
- Single Game shows a CFB-style TOP MARKET card plus a ranked market board.
- Manual odds editing is demoted to Advanced Tools instead of being the primary workflow.
- Full Slate uses CFB-style "Slate Betting Card", Top 5 / Top 10, A/B-only official card, separate C leans and chronological All Games.
- Added slate A/B/C counts.
- Model logic from v0.9.1 is otherwise preserved.

Important
=========
The market feed is a generic current-market snapshot, not a verified opener or closing line.
The v0.9 probability calibration remains conservative and should be validated with a proper historical backtest.
